# Notes App

A full-stack notes application created for the USM Computer Science Society technical test.

The repository currently contains the initial React project structure and planning documentation. Product features will be delivered incrementally according to the five assessment levels.

## Technology direction

- React and Vite for the client application
- Node.js and Express for the REST API
- PostgreSQL with Prisma ORM for persistent storage
- JSON Web Tokens stored in secure HTTP-only cookies for authentication

## Getting started

### Prerequisites

- Node.js 20.19 or newer
- npm 10 or newer
- Git

### Installation

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Available commands

```bash
npm run dev      # Start the frontend development server
npm run build    # Create a production build
npm run lint     # Run static code checks
npm run preview  # Preview the production build locally
```
